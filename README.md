## Agrep (A simple grep like CLI tool)

A simple command-line tool inspired by grep, built in Rust as part of my journey to deeply understand core Rust concepts like ownership, structs, enums, options, and error handling.

## Motivation

I originally built a basic version of this tool before fully understanding Rust’s core concepts.
After learning:

- Ownership & Borrowing
- Structs
- Enums & Option
- Error Handling (Result, unwrap, ?)

I rebuilt the project from scratch.

This version reflects a much deeper understanding of Rust and cleaner design decisions.
